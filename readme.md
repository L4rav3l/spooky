About Project
Step into a cozy, atmospheric management simulation where you run your very own seasonal autumn market! Engage in delightful conversations with charming customers, carefully carve intricate pumpkins, and sell your creations to turn a profit. Explore the mysterious surrounding forest to forage for wild pumpkins and purchase essential candles to keep your shop glowing. Time management is crucial, as you are granted a strict 300-second window after market closing to prepare for the next bustling day.

Tech Stack & Demo
Built using C# and MonoGame.

Watch the gameplay demo on YouTube: https://youtu.be/iGCG8TX4jWc

Build Commands   
Linux: ```dotnet publish -c Release -r linux-x64 -p:PublishReadyToRun=false -p:TieredCompilation=false --self-contained```

macOS: ```dotnet publish -c Release -r osx-x64 -p:PublishReadyToRun=false -p:TieredCompilation=false --self-contained```

Windows: ```dotnet publish -c Release -r win-x64 -p:PublishReadyToRun=false -p:TieredCompilation=false --self-contained```
